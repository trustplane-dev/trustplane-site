Auth plane & tooling

Run it where your workloads run.

COMMAND-LINE INTERFACE

TrustPlane CLI preview

Generate keys, sign request proofs, sign policy bundles, and operate the auth plane from your terminal and CI.

curl -fsSL https://downloads.auth.trustplane.dev/install.sh | sh
KUBERNETES

Helm chart preview

Deploy the provider adapter and local broker into your cluster with a single chart.

helm install trustplane-auth \ oci://ghcr.io/trustplane-dev/charts/trustplane-auth
CONTAINER IMAGES

Adapter & broker images preview

Digest-pinned container images for the provider adapter and the local broker, ready for any orchestrator.

docker pull ghcr.io/trustplane-dev/adapter:latest
CONFORMANCE

Conformance vectors

Shared test vectors, so every SDK and integration produces and verifies request proofs identically.

github.com/trustplane-dev · conformance vectors
SDKs

Sign request proofs from your language.

GO

sdk-go preview

Sign request proofs from Go services and agents.

go get github.com/trustplane-dev/trustplane-auth-sdk-go
TYPESCRIPT / NODE

sdk-js preview

Sign request proofs from Node.js and TypeScript runtimes.

npm install @trustplane/sdk
