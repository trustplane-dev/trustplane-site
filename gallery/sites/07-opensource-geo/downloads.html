Runtime & tooling

Run it where your workloads run.

COMMAND-LINE INTERFACE

TrustPlane CLI preview

Sign proofs, manage trust material, and operate the runtime from your terminal and CI.

curl -fsSL https://downloads.auth.trustplane.dev/install.sh | sh
KUBERNETES

Helm chart preview

Deploy the verifying adapter and broker into your cluster with a single chart.

helm install trustplane-auth \ oci://ghcr.io/trustplane-dev/charts/trustplane-auth
CONTAINER IMAGES

Adapter & broker images preview

Published container images for the verifying adapter and broker, ready for any orchestrator.

docker pull ghcr.io/trustplane-dev/adapter:latest
CONFORMANCE

Conformance vectors

Shared test vectors so every SDK and integration verifies proofs identically.

github.com/trustplane-dev · conformance vectors
