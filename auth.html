TrustPlane Auth

Runtime authorization where machine traffic enters.

TrustPlane Auth enforces near protected APIs, tools, and services. It verifies machine requests, applies local policy, denies unsafe calls early, and emits decision evidence.

Runtime job

Make the boundary smart enough to say no.

A machine caller should not get a free pass because it has a token-shaped string. Auth evaluates caller, request, policy, freshness, and replay signals before forwarding traffic.

Capabilities

What Auth handles in the request path.

Verification

Request-aware decisions

Evaluate machine requests using caller identity, intended action, target audience, route, method, freshness, and policy context.

Replay resistance

Stop reused authorization material

Detect replay and mismatch conditions before traffic reaches sensitive APIs or tool handlers.

Local enforcement

No per-request dependency on Control

Auth is built to make decisions locally using trusted configuration and policy state distributed to the runtime.

Integration

Fit existing infrastructure

Use gateway, sidecar, service-adjacent, or cluster deployment models rather than rewriting every protected application.

Evidence

Emit useful audit events

Record allow and deny decisions with the policy and caller context operators need during reviews and incidents.

Operations

Clear failure modes

Stable deny reasons help engineering teams debug access without hiding security decisions behind generic 403s.
